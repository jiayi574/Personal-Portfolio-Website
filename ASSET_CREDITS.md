# Asset credits

## Original assets

All room furniture, architecture, keyboard keys, monitor and CRT housings, turntable, records, sleeves, chair, shelves, books, lamps, plants, clock, mug, notebook, posters, noticeboard, crate, rug and mascot were authored for this project in `src/components/RoomScene.tsx`. They are composed into detailed original objects from custom-arranged geometry; no third-party 3D models or proprietary reference assets were downloaded or reused.

Wood, wall and rug textures are deterministic procedural canvas textures. All framed graphics, decorative sleeve designs, terminal screens, CSS illustrations and the sticker SVG are original. No commercial album artwork, music recording, brand logo or reference copy is included. The ambient sound uses Web Audio sine oscillators.

The reference screenshots are retained solely as development comparison evidence, not as website assets or licensed artwork for redistribution. The reference remains the property of its respective creators. Remove reference evidence before redistributing the source package publicly if necessary.
